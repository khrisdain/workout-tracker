What PulseTrack is, and what it deliberately is not

PulseTrack is a training log built around one idea: the number that changes behaviour is not the one from a single session, it is the trend across a month.

Most fitness apps optimise for the moment you finish a workout. This one optimises for the Sunday evening when you want to know whether the last four weeks actually added up to anything. That is why every screen leads with volume, split and consistency rather than a single hero number, and why the sample database ships with five weeks of history instead of an empty table.

How it is put together

Primary application
Spring Boot with Thymeleaf and Bootstrap on the front, Spring Data JPA on the back, Spring Security for accounts and roles.
Nutrition microservice
A second, independently deployable Spring Boot application with its own database and its own Basic Auth users. PulseTrack calls it over REST and degrades gracefully when it is not running.
Configuration
Hierarchical YAML. The dev profile runs on in-memory H2, the prod profile on MySQL, and switching between them is a command line flag, never a code change.
